# Screenshots

The pictures in the user guide and the README, all made from the demo home by
`npm run screenshots` in `frontend/` ([tools/screenshots.mjs](../../tools/screenshots.mjs)): a
fixed window size, a fixed clock (an afternoon in May, or a January evening), the demo's pretend
states with a fixed seed, and the camera where the view puts it. `npm run screenshots -- night day`
makes the ones named. See [Screenshots](../DEVELOPMENT.md#screenshots) in DEVELOPMENT.md.
