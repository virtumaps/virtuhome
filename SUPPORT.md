# Getting help with VirtuHome

**Start with the [user guide](docs/GUIDE.md)**, and its [FAQ](docs/GUIDE.md#faq) and
[troubleshooting](docs/GUIDE.md#troubleshooting) sections.

| You want to… | Go to |
|---|---|
| ask how to do something, or whether something is supported | [Discussions → Q&A](https://github.com/virtumaps/virtuhome/discussions/categories/q-a) |
| suggest an idea, or vote for one | [Discussions → Ideas](https://github.com/virtumaps/virtuhome/discussions/categories/ideas) |
| show your home or your wall tablet | [Discussions → Show and tell](https://github.com/virtumaps/virtuhome/discussions/categories/show-and-tell) |
| report something that doesn't work | [a bug report](https://github.com/virtumaps/virtuhome/issues/new?template=bug_report.yml) |
| ask for a device or integration to be supported | [a device support request](https://github.com/virtumaps/virtuhome/issues/new?template=device_support.yml) |
| report a scan or floor plan picture that came in wrong | [an import problem](https://github.com/virtumaps/virtuhome/issues/new?template=import_problem.yml) |
| report that it's slow on a device | [a slow device report](https://github.com/virtumaps/virtuhome/issues/new?template=slow_device.yml) |

## What to attach

- **The diagnostics file:** Settings → Devices & services → VirtuHome → ⋮ → **Download
  diagnostics**. It holds the versions, the plan's size and what each floor counts, how the card
  reaches your dashboards, which extensions are loaded and the last errors the cards and the panel
  ran into. It has no room, device or entity names, no web addresses, and no licence key or token.
- The VirtuHome and Home Assistant versions, and the device and browser or app.
- A screenshot, with anything private taken out. Everything on GitHub is public.

## How fast we answer

VirtuHome is made by a small team. We read every question and issue, and usually answer within a
few days. Questions answered in Discussions help the next person too, so please ask there rather
than by email.

## Installation clients and extensions

If VirtuMaps installed your smart home, use the contact you were given. For help with a licence key
or an extension, email info@virtumaps.com.

## Security problems

Please don't post a security problem publicly. Email info@virtumaps.com and we'll reply there.
